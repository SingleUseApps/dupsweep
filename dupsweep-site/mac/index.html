How it works on macOS

You pick the folders to scan — Downloads, Desktop, an external drive, or a copy you made when you migrated from an old Mac. DupSweep groups likely matches by name and size, then verifies file duplicates with SHA-256 so two files only count as the same if their contents match byte-for-byte.

Nothing is deleted until you choose. Removed files go to the macOS Trash, not a permanent wipe. While the app is open, ⌘Z undoes the last cleanup. After you quit, you can still restore from Trash until you empty it.

What you can clean

Downloads and Desktop clutter

Installers, AirDrop copies, and “final_final” exports that piled up next to the originals.

After a Mac migration

A Migration Assistant copy plus files you dragged from the old disk often leave whole folder trees duplicated.

Photos and screenshots

Near-duplicates from bursts, exports, and messaging apps. See the similar photos page.

External drives

USB and external disks work if they are mounted. Avoid scanning the System volume itself.
