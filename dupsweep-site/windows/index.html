How it works on Windows

Point DupSweep at the folders you care about — Downloads, Desktop, Pictures, or a disk you copied from an old PC. It groups likely matches by name and size, then verifies file duplicates with SHA-256. Two files only count as duplicates if the contents are identical.

You choose what to remove. Files go to the Recycle Bin, not a permanent wipe. While DupSweep is open, Ctrl+Z undoes the last cleanup. After you quit, restore from the Recycle Bin until you empty it.

What you can clean

Downloads, Desktop, Documents

Setup files, zip extracts, and copies you saved “just in case” next to the original.

After moving from an old PC

A full disk copy plus files you already had on the new machine often duplicates whole folder trees.

OneDrive

Scan your OneDrive folder to find the same file sitting in the cloud sync and somewhere else on the PC. Download online-only files first so they are really on disk.

Phone dumps and WhatsApp

Pictures copied from a phone, then again from chat exports. See similar photos.

External and network drives

USB disks work when they have a drive letter. Network shares usually work if they appear as folders; speed depends on the network.

Windows-specific notes

  • SmartScreen may warn on first launch — the installer is not signed yet. Choose “More info” → Run anyway if you downloaded it from this site or GitHub Releases.
  • OneDrive: add the OneDrive folder to the scan. Files marked online-only must be made available offline first, or they are only placeholders.
  • Avoid scanning C:\Windows and Program Files. You pick the folders; DupSweep does not lock the OS away for you.
