Find duplicate folders, not just duplicate files

A whole project folder copied twice isn't ten duplicate files — it's one duplicate folder. DupSweep clusters folders by shared content and merges them safely, with a full preview before anything changes.

Whole folders, not just files

Two folders cluster together once their shared content meets a match threshold (75% by default, adjustable). Matching is based on the same content hashes as Files mode — no guessing from names alone.

Merge & Clean moves the files unique to the duplicate into the folder you keep, then trashes the rest. Prefer to leave originals untouched entirely? Turn on Copy to new folder and the merged result is written somewhere new instead. Either way, every operation shows an exact preview — which files get kept, moved, or deleted — before you commit to it.

Review One-by-One steps through every cluster for individual approval; Merge All Folders runs the whole batch at once. Clusters are collapsible, and you can rename the kept folder after merging.

When this helps

💻 Migration Assistant copies

An old Mac or PC's disk copied over wholesale, duplicating entire folder trees next to what's already there.

🗂️ "v1 / v2 / final" project backups

Snapshot backups of a project folder taken at different points, mostly identical to each other.

📦 Re-extracted archives

The same zip extracted more than once, into a new folder each time instead of overwriting.

☁️ OneDrive folder

A OneDrive folder on disk duplicated locally — same content-hash comparison as any other folder.

What it does not do

  • It does not merge cloud-only placeholder files (iCloud / OneDrive online-only). Make them available offline first.
  • Folders with mostly-different content simply won't cluster — that's by design. Lower the match threshold to catch looser overlaps, or raise it for near-identical folders only.
  • It does not touch anything without a preview first, even in Merge All Folders — you always see the operation counts before committing.
