How it works

You pick the folders to scan — Downloads, Desktop, Pictures, an external drive, or a copy you made when you migrated from an old computer. DupSweep groups likely matches by name and size, then verifies file duplicates with SHA-256 so two files only count as the same if their contents match byte-for-byte.

On your platform

🍎 macOS

  • Deletions: go to Trash
  • Undo shortcut: ⌘Z while app is open
  • After quit: restore from Trash until you empty it

⊞ Windows

  • Undo shortcut: Ctrl+Z while app is open
  • After quit: restore from Recycle Bin until you empty it

What you can clean

📥 Downloads & Desktop clutter

Installers, AirDrop copies, setup files, zip extracts, and "final_final" exports that piled up next to the originals.

💻 Coming from your old computer

A Migration Assistant copy (Mac) or old PC disk (Windows) plus files you dragged over often leave whole folder trees duplicated.

☁️ OneDrive

If OneDrive keeps a folder on disk, add that folder to the scan. Same SHA-256 check as any other path. Make online-only files available offline first.

🖼️ Photos & screenshots

Near-duplicates from bursts, exports, and messaging apps. See the similar photos page for perceptual hashing.

💾 External & network drives

USB disks and external drives work if mounted. Windows also scans network shares if they appear as folders.

Smart for photos, rigorous for files

Byte-for-byte verification + perceptual hashing. Nothing gets removed without proof.
